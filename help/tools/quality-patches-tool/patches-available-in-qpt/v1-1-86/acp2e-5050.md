# ACP2E-5050：在「管理員」中檢視或儲存RMA時，不會在動作記錄報表中顯示RMA編號

ACP2E-5050修補程式修正了在管理員中檢視或儲存RMA時，**[!UICONTROL Action Logs]**&#x200B;報表中未顯示RMA號碼的問題。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86時，即可使用此修補程式。 修補程式ID為ACP2E-5050。 請注意，此問題已排程在Adobe Commerce 2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.8-p5

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） 2.4.6 - 2.4.9

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hant)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

在管理員中檢視或儲存RMA時，**[!UICONTROL Action Logs]**&#x200B;報告中不會顯示RMA編號。

<u>要再現的步驟</u>：

1. 在店面或管理面板中訂購簡單產品。
1. 在管理員面板中，移至&#x200B;**[!UICONTROL Sales]** > **[!UICONTROL Orders]**，開啟訂單，按一下&#x200B;**[!UICONTROL Ship]**，然後按一下&#x200B;**[!UICONTROL Submit Shipment]**。
1. 在訂單頁面上，按一下&#x200B;**[!UICONTROL Create Returns]**。 在&#x200B;**[!UICONTROL Return Items]**&#x200B;索引標籤上，按一下&#x200B;**[!UICONTROL Add Products]**，選取產品，然後按一下&#x200B;**[!UICONTROL Add Selected Product(s) to returns]**。
1. 輸入&#x200B;**[!UICONTROL Requested]**&#x200B;數量，選取&#x200B;**[!UICONTROL Return Reason]**、**[!UICONTROL Item Condition]**&#x200B;和&#x200B;**[!UICONTROL Resolution]**，然後按一下&#x200B;**[!UICONTROL Submit Returns]**。
1. 前往&#x200B;**[!UICONTROL Sales]** > **[!UICONTROL Returns]**&#x200B;並開啟新的傳回。
1. 移至&#x200B;**[!UICONTROL System]** > **[!UICONTROL Action Logs]** > **[!UICONTROL Report]**，將&#x200B;**[!UICONTROL Action Group]**&#x200B;篩選器設定為&#x200B;*Returns*，按一下&#x200B;**[!UICONTROL Search]**，然後檢查&#x200B;**[!UICONTROL Details]**&#x200B;欄。

<u>預期結果</u>：

提交傳回時記錄了&#x200B;*Save*&#x200B;專案，而開啟時記錄的&#x200B;*View*&#x200B;專案在&#x200B;**[!UICONTROL Details]**&#x200B;欄中顯示其RMA編號。

<u>實際結果</u>：

這些專案在&#x200B;**[!UICONTROL Details]**&#x200B;欄中只顯示破折號，不顯示RMA編號。
