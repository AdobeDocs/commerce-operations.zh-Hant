# ACP2E-4973：從店內傳遞切換至其他傳遞方式時，不會從購物車中清除商店位址

ACP2E-4973修補程式修正了從&#x200B;**[!UICONTROL In-Store Delivery]**&#x200B;切換至其他傳遞方式時，無法從購物車中清除商店位址的問題。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86時，即可使用此修補程式。 修補程式ID為ACP2E-4973。 請注意，此問題已排程在Adobe Commerce 2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.8-p5

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） 2.4.8-p1 - 2.4.8-p5

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hant)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

從&#x200B;**[!UICONTROL In-Store Delivery]**&#x200B;切換至其他傳遞方式時，不會從購物車中清除商店位址。

<u>必要條件</u>：

Inventory management （多Source詳細目錄）和店內取貨。

<u>要再現的步驟</u>：

1. 在Admin中，移至&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Sources]**&#x200B;並按一下&#x200B;**[!UICONTROL Add New Source]**。 輸入&#x200B;**[!UICONTROL Name]**&#x200B;和&#x200B;**[!UICONTROL Code]**，啟用&#x200B;*作為取車地點*，在&#x200B;**[!UICONTROL Contact Info]**&#x200B;下輸入&#x200B;**[!UICONTROL Phone]**，在&#x200B;**[!UICONTROL Address Data]**&#x200B;下輸入&#x200B;**[!UICONTROL Country]**、**[!UICONTROL State/Province]**、**[!UICONTROL City]**、**[!UICONTROL Street]**&#x200B;和&#x200B;**[!UICONTROL Postcode]**，並儲存來源。
1. 前往&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stocks]**，然後按一下&#x200B;**[!UICONTROL Add New Stock]**。 輸入&#x200B;**[!UICONTROL Name]**，在&#x200B;**[!UICONTROL Sales Channels]**&#x200B;下選取網站，在&#x200B;**[!UICONTROL Sources]**&#x200B;下指派新來源，然後儲存庫存。
1. 前往&#x200B;**[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;並建立簡單的產品。 在&#x200B;**[!UICONTROL Sources]**&#x200B;區段中，按一下&#x200B;**[!UICONTROL Assign Sources]**、選取新來源、輸入正數並儲存產品。
1. 移至&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL Sales]** > **[!UICONTROL Delivery Methods]**，展開&#x200B;**[!UICONTROL In-Store Delivery]**，將&#x200B;**[!UICONTROL Enabled]**&#x200B;設定為&#x200B;*是*，然後按一下&#x200B;**[!UICONTROL Save Config]**。
1. 將GraphQL作為註冊客戶使用，產生客戶權杖(`generateCustomerToken`)，取得購物車識別碼(`customerCart`)，然後將產品新增到購物車(`addProductsToCart`)。
1. 在`pickup_location_code`中只傳送原始程式碼，將購物車送貨地址設定為取貨地點：

   ```
   mutation {
     setShippingAddressesOnCart(input: {
       cart_id: "<cart_id>"
       shipping_addresses: [{ pickup_location_code: "<source_code>" }]
     }) {
       cart { shipping_addresses { pickup_location_code firstname lastname street city postcode } }
     }
   }
   ```

1. 將購物車切換到&#x200B;**[!UICONTROL Flat Rate]**&#x200B;並在回應中檢查`shipping_addresses`：

   ```
   mutation {
     setShippingMethodsOnCart(input: {
       cart_id: "<cart_id>"
       shipping_methods: [{ carrier_code: "flatrate", method_code: "flatrate" }]
     }) {
       cart { shipping_addresses { pickup_location_code firstname lastname street city postcode } }
     }
   }
   ```

1. 設定帳單地址(`setBillingAddressOnCart`)和付款方式（`setPaymentMethodOnCart`，例如`checkmo`），然後執行`placeOrder`而不設定新的送貨地址。

<u>預期結果</u>：

1. 在切換至&#x200B;**[!UICONTROL Flat Rate]**&#x200B;之後，`pickup_location_code`和取車商店地址會從購物車送貨地址中移除。
1. 您必須使用`setShippingAddressesOnCart`設定有效的住家交貨運送地址，才能下訂單。

<u>實際結果</u>：

1. 切換至&#x200B;**[!UICONTROL Flat Rate]**&#x200B;後，購物車送貨地址仍包含`pickup_location_code`和取車商店地址。
1. 已下訂單。 在&#x200B;**[!UICONTROL Sales]** > **[!UICONTROL Orders]**&#x200B;中，訂單的送貨地址是取貨商店地址，儘管交貨方式為&#x200B;**[!UICONTROL Flat Rate]**。
