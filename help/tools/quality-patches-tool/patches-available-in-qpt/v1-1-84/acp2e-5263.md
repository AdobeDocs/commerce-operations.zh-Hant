# ACP2E-5263：產品CSV匯出提早停止並省略產品

ACP2E-5263修補程式修正CSV產品匯出在包含所有產品之前可能會停止的問題，這會產生不完整的檔案。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84時，即可使用此修補程式。 修補程式ID為ACP2E-5263。 請注意，此問題已排程在Adobe Commerce 2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.8-p5

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hant)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

將產品匯出至CSV時，必須先包含所有產品，否則會產生不完整的檔案。

<u>要再現的步驟</u>：

1. 確定目錄包含多個產品和一個次要商店檢視。
2. 使用測試產品，其中的影像標籤已設定為次要商店檢視，但在預設商店檢視中沒有對應的產品影像可用。
3. 在Admin中，移至&#x200B;**[!UICONTROL System]** > **[!UICONTROL Data Transfer]** > **[!UICONTROL Export]**。
4. 將&#x200B;**[!UICONTROL Entity Type]**&#x200B;設為&#x200B;**[!UICONTROL Products]**&#x200B;並將&#x200B;**[!UICONTROL Export File Format]**&#x200B;保留設為&#x200B;**[!UICONTROL CSV]**。
5. 匯出篩選器保持空白，不排除屬性。
6. 向下捲動並按一下&#x200B;**[!UICONTROL Continue]**。
7. 等候非同步匯出完成，然後下載並開啟CSV檔案。

<u>預期結果</u>：

匯出完成並產生包含每個產品的CSV。

<u>實際結果</u>：

匯出作業會中止，但管理員指出匯出檔案已就緒，且提供的CSV缺少部分產品。
