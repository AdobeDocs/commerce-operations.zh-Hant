# ACP2E-5027：當應用程式鎖定使用檔案鎖定提供者時，索引子沒有完成

ACP2E-5027修補程式修正了當啟用`use_application_lock`且設定檔案鎖定提供者時，索引子會持續嘗試取得自己的鎖定，因而無法完成的問題。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84時，即可使用此修補程式。 修補程式ID為ACP2E-5027。 此問題已排程在Adobe Commerce 2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.9

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） 2.4.4 - 2.4.9

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hant)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

索引子永遠不會完成，因為啟用`use_application_lock`且已設定檔案鎖定提供者時，索引子會繼續嘗試取得自己的鎖定。

<u>要再現的步驟</u>：

1. 在`app/etc/env.php`中，啟用索引器的應用程式鎖定，並將鎖定提供者設定為檔案：

   ```
   'indexer' =>
   array (
     'use_application_lock' => true,
   ),
   'lock' =>
   array (
     'provider' => 'file',
     'config' =>
     array (
       'path' => '<magento_root>/var/lock',
     ),
   )
   ```

1. 執行`catalog_product_category`索引子：

   ```
   bin/magento indexer:reindex catalog_product_category
   ```

<u>預期結果</u>：

`catalog_product_category`重新索引成功完成。

<u>實際結果</u>：

重新索引永遠不會完成。
