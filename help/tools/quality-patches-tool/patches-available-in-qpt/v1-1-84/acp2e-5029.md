# ACP2E-5029：目錄價格規則變更不會同步至「即時搜尋」價格摘要

ACP2E-5029修補程式修正了目錄價格規則變更未透過一般價格摘要同步傳送至[!DNL Live Search]的問題，因此更新的價格只會在強制重新同步後顯示。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84時，即可使用此修補程式。 修補程式ID為ACP2E-5029。 請注意，此問題已排程在Adobe Commerce 2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.7-p9

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） 2.4.7 - 2.4.9

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

一般價格摘要同步處理不會將目錄價格規則變更傳送至[!DNL Live Search]，因此更新的價格只會在強制重新同步後顯示。

<u>必要條件</u>：

[!DNL Live Search]和內容暫存已啟用，且索引子設定為&#x200B;*[!UICONTROL Update by Schedule]*。
此問題間歇性：當索引cron群組已重新索引時，暫存cron群組套用排程更新時會發生此問題。

<u>要再現的步驟</u>：

1. 請確定要折扣的產品可透過[!DNL Live Search]搜尋。
1. 在Admin中，移至&#x200B;**[!UICONTROL Marketing]** > **[!UICONTROL Promotions]** > **[!UICONTROL Catalog Price Rule]**&#x200B;並按一下&#x200B;**[!UICONTROL Add New Rule]**。 將&#x200B;**[!UICONTROL Active]**&#x200B;設為&#x200B;*否*，在&#x200B;**[!UICONTROL Customer Groups]**&#x200B;下選取適用的網站和&#x200B;**[!UICONTROL NOT LOGGED IN]**&#x200B;客戶群組，並定義產品的條件。 在&#x200B;**[!UICONTROL Actions]**&#x200B;下，將&#x200B;**[!UICONTROL Apply]**&#x200B;設定為&#x200B;*[!UICONTROL Apply as percentage of original]*，輸入&#x200B;**[!UICONTROL Discount Amount]**，然後按一下&#x200B;**[!UICONTROL Save]**。
1. 在規則編輯頁面的&#x200B;**[!UICONTROL Scheduled Changes]**&#x200B;區段中，按一下&#x200B;**[!UICONTROL Schedule New Update]**。 Select **[!UICONTROL Save as a New Update]**，輸入&#x200B;**[!UICONTROL Update Name]**，將&#x200B;**[!UICONTROL Start Date]**&#x200B;設定為已知的未來時間，在&#x200B;**[!UICONTROL Rule Information]**&#x200B;下將&#x200B;**[!UICONTROL Active]**&#x200B;設定為&#x200B;*是*，然後按一下&#x200B;**[!UICONTROL Save]**。
1. 在「開始日期」之後，等候目錄規則產品和目錄產品規則索引器完成，然後將其中一個產品新增至店面的購物車，並檢查是否套用折扣價格。
1. 不要觸發強制重新同步。 允許執行索引cron群組中的下一個一般價格摘要同步，並檢查`var/log/commerce-data-export.log`中的`prices`摘要專案。
1. 搜尋[!DNL Live Search]店面中受影響的產品，並將顯示的價格與作用中「目錄價格規則」所計算的價格進行比較。

<u>預期結果</u>：

1. 一般的價格摘要同步會偵測目錄價格規則變更，並報告受影響產品的非零同步計數。
1. [!DNL Live Search]顯示更新的價格，不需要強制重新同步。

<u>實際結果</u>：

1. 索引cron群組中的下一個一般價格摘要同步處理所有產品，但報表同步為&#x200B;*0*。
1. [!DNL Live Search]會繼續顯示舊價格，直到強制重新同步執行為止。
