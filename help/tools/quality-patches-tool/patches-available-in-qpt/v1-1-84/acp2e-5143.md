# ACP2E-5143： GraphQL `route`查詢轉譯未請求的CMS頁面內容

ACP2E-5143修補程式修正GraphQL `route`查詢轉譯完整的CMS頁面內容的問題，包含頁面產生器介面工具集和產品清單，即使僅要求URL路由欄位亦然，這會降低URL解析速度。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84時，即可使用此修補程式。 修補程式ID為ACP2E-5143。 請注意，此問題已排程在Adobe Commerce 2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.7-p9

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） 2.4.4 - 2.4.7-p10

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

GraphQL `route`查詢轉譯完整的CMS頁面內容（包括頁面產生器Widget和產品清單）的問題，即使僅要求URL路由欄位也一樣，這會降低URL解析速度。

<u>必要條件</u>：

頁面產生器已安裝。

<u>要再現的步驟</u>：

1. 前往「管理員> **[!UICONTROL Content]** > **[!UICONTROL Elements]** > **[!UICONTROL Pages]**」，然後按一下&#x200B;**[!UICONTROL Add New Page]**。
1. 輸入頁面詳細資料，將&#x200B;**[!UICONTROL Enable Page]**&#x200B;設定為&#x200B;**[!UICONTROL Yes]**，然後按一下&#x200B;**[!UICONTROL Content]**&#x200B;區段中的&#x200B;**[!UICONTROL Edit with Page Builder]**。 展開「頁面產生器」面板中的&#x200B;**[!UICONTROL Add Content]**，並將&#x200B;**[!UICONTROL Products]**&#x200B;預留位置拖曳到舞台上，或將目錄產品Widget插入頁面內容。
1. 在Admin中，移至&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]**。 在左側面板的&#x200B;**[!UICONTROL General]**&#x200B;下，選擇&#x200B;**[!UICONTROL Web]**，然後展開&#x200B;**[!UICONTROL Default Pages]**。 將&#x200B;**[!UICONTROL CMS Home Page]**&#x200B;設定為新頁面，然後按一下&#x200B;**[!UICONTROL Save Config]**。
1. 傳送下列GraphQL請求：

   ```
   query ResolveURL($url: String!) {
     route(url: $url) {
       relative_url
       redirect_code
       type
       ... on CmsPage { identifier __typename }
       ... on ProductInterface { uid __typename }
       ... on CategoryInterface { uid __typename }
       __typename
     }
   }
   ```

1. 針對請求使用下列變數：

   ```
   { "url": "/" }
   ```

<u>預期結果</u>：

`route`查詢會傳回CMS首頁的請求路由中繼資料和型別辨識器欄位，而不會呈現其完整內容。

<u>實際結果</u>：

1. 即使只要求路由中繼資料和型別鑑別子欄位，`route`查詢也會轉譯完整的CMS首頁內容。
1. 頁面產生器Widget會載入產品集合，增加回應時間以及每個請求的資料庫查詢數。
