# ACP2E-5017：沒有公司的客戶的GraphQL客戶角色查詢失敗

ACP2E-5017修補程式修正GraphQL `customer`查詢的`role`欄位傳回&#x200B;*內部伺服器錯誤*&#x200B;給未指派給公司的客戶的問題。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84時，即可使用此修補程式。 修補程式ID為ACP2E-5017。 請注意，此問題已排程在Adobe Commerce B2B 1.5.4中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） B2B 1.5.3

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） B2B 1.5.0 - 1.5.3

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hant)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

GraphQL `customer`查詢的`role`欄位傳回未指派給公司的客戶的&#x200B;*內部伺服器錯誤*。

<u>必要條件</u>：

已安裝B2B。

<u>要再現的步驟</u>：

1. 在Admin中，移至&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL B2B Features]**，將&#x200B;**[!UICONTROL Enable Company]**&#x200B;設定為&#x200B;*[!UICONTROL Yes]*，然後按一下&#x200B;**[!UICONTROL Save Config]**。
1. 建立未指派給公司的客戶帳戶。
1. 使用有效的客戶Token傳送下列GraphQL查詢：

```
   query {
     customer {
       email
       firstname
       role {
         id
         name
       }
     }
   }
```

<u>預期結果</u>：

查詢傳回客戶資料，`role`設定為&#x200B;*null*，沒有錯誤。

<u>實際結果</u>：

查詢傳回&#x200B;*內部伺服器錯誤*。
