# ACP2E-4840： GraphQL產品查詢針對自訂存貨存貨上的庫存產品傳回null數量

ACP2E-4840修補程式修正產品GraphQL查詢中的數量欄位，針對有庫存且可在自訂存貨上銷售的產品傳回null的問題。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82時，即可使用此修補程式。 修補程式ID為ACP2E-4840。 請注意，此問題已排程在Adobe Commerce 2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.8-p4

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hant)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

產品GraphQL查詢中的數量欄位會針對庫存中的產品傳回Null，這些產品可在自訂存貨存貨上銷售。

<u>必要條件</u>：

MSI已啟用。

<u>要再現的步驟</u>：

1. 建立新的來源。
1. 在管理員側邊欄上，前往&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**。
1. 按一下&#x200B;**[!UICONTROL Add New Stock]**。
1. 展開&#x200B;**[!UICONTROL Sales Channels]**&#x200B;並選取有可用庫存的&#x200B;**[!UICONTROL Websites]**。
1. 展開&#x200B;**[!UICONTROL Sources]**，按一下&#x200B;**[!UICONTROL Assign Sources]**，選取您要指派的來源，然後按一下&#x200B;**[!UICONTROL Done]**。
1. 在管理員側邊欄上，前往&#x200B;**[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;並以編輯模式開啟現有產品。
1. 在&#x200B;**[!UICONTROL Sources]**&#x200B;區段中，指派自訂來源、將&#x200B;**[!UICONTROL Source Item Status]**&#x200B;設定為&#x200B;**[!UICONTROL In Stock]**、輸入&#x200B;**[!UICONTROL Qty]**&#x200B;的非零值，然後儲存產品。
1. 在&#x200B;**[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;中確認產品針對指派給自訂庫存的網站顯示非零&#x200B;**[!UICONTROL Salable Quantity]**。
1. 針對指派給使用自訂庫存之網站的商店檢視，針對該SKU執行下列`products` [!DNL GraphQL]查詢：

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. 觀察回應：

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>預期結果</u>：

GraphQL回應會針對目前商店/網站上已有庫存且可銷售的產品傳回非Null數量值。

<u>實際結果</u>：

當商店使用自訂MSI庫存時，對於有庫存且在管理員中可銷售的產品，GraphQL回應會傳回`quantity = null`，而`stock_status` = `IN_STOCK`。
