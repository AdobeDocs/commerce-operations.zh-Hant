# ACP2E-4799： GraphQL查詢`requisition_lists`傳回錯誤的分頁`total_count`

ACP2E-4799修補程式修正`requisition_lists` GraphQL查詢傳回不正確的`total_count`值的問題，該值僅反映目前頁面上的專案數，而非符合查詢條件的請購單清單實體總數。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82時，即可使用此修補程式。 修補程式ID為ACP2E-4799。 請注意，此問題已排程在Adobe Commerce B2B 1.5.4中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） B2B 1.5.2-p4

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） B2B >=1.5.0 &lt;1.5.3

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

當客戶查詢具有分頁的請購單清單時，`total_count`欄位未反映相符請購單清單的完整數目。 相反地，它只報告目前頁面傳回的專案數，這會使分頁中繼資料不正確。

<u>必要條件</u>：

Adobe Commerce B2B已啟用請購單清單。

<u>要再現的步驟</u>：

1. 在Admin中，移至&#x200B;**[!UICONTROL Stores]** > **設定** > **設定**。
1. 在左側面板的&#x200B;**一般**&#x200B;下，選擇&#x200B;**B2B功能**。
1. 將&#x200B;**[!UICONTROL Enable Requisition List]**&#x200B;設為&#x200B;**[!UICONTROL Yes]**&#x200B;並選取&#x200B;**[!UICONTROL Save Config]**。
1. 以客戶身分登入店面。
1. 選擇&#x200B;**[!UICONTROL My Requisition Lists]**&#x200B;並建立六個請購單清單。
1. 請確定客戶只有六個請購單清單，且每個清單名稱都包含`ABC`，因此所有六個清單都與篩選的查詢相符。
1. 執行下列GraphQL查詢，`pageSize`設為2且`currentPage`設為1：

   ```graphql
   query {
     customer {
       requisition_lists(
         pageSize: 2
         currentPage: 1
       ) {
         items {
           uid
           name
         }
         total_count
         page_info {
           current_page
           page_size
           total_pages
         }
       }
     }
   }
   ```

1. 執行此GraphQL查詢：

   ```graphql
   query {
     customer {
       requisition_lists(
         filter: { name: { match: "%ABC%" } }
         pageSize: 2
         currentPage: 1
       ) {
         items {
           uid
           name
         }
         total_count
         page_info {
           current_page
           page_size
           total_pages
         }
       }
     }
   }
   ```


<u>預期結果</u>：

* `requisition_lists`查詢傳回`total_count`等於客戶擁有的請購單清單總數，獨立於`pageSize`和`currentPage`。
* 分頁資料會與完整相符的結果集保持一致。

<u>實際結果</u>：

`total_count`只傳回目前頁面中的專案數，例如2個而非6個。
