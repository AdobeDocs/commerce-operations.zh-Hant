# AC-18128：非英文地區設定的GraphQL訂單日期和註解時間戳記不正確

AC-18128修補程式修正GraphQL傳回的訂單日期和訂單評論時間戳記在非英文地區設定中顯示錯誤行事曆日期的問題。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83時，即可使用此修補程式。 修補程式ID為AC-18128。 請注意，此問題已在Adobe Commerce 2.4.8中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.8

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） >=2.4.8 &lt;2.4.8-p6

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hant)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

GraphQL傳回的訂單日期和訂單評論時間戳記在非英文地區設定中顯示錯誤的日曆日期。

<u>要再現的步驟</u>：

1. 在管理面板中，移至&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL Locale Options]**。 將&#x200B;**[!UICONTROL Timezone]**&#x200B;設為&#x200B;*歐洲/巴黎*。 將&#x200B;**[!UICONTROL Locale]**&#x200B;設為&#x200B;*法文（法國）*。 儲存設定。
1. 在店面下訂單。
1. 執行以下客戶訂單GraphQL查詢：

   ```graphql
   query getOrders {
       customer {
           orders {
               items {
                   orderDateOK: created_at
                   orderDateFAIL: order_date
               }
           }
       }
   }
   ```

<u>預期結果</u>：

GraphQL回應中的訂單日期和評論時間戳記反映正確的行事曆日期，無論商店地區設定為何。

<u>實際結果</u>：

針對非`en_US`地區（例如`fr_FR`和`de_DE`），`order_date`顯示錯誤的行事曆日期，因為有日期剖析問題。
