# ACP2E-5205：大型目錄會導致管理員中的類別載入緩慢和逾時

ACP2E-5205修補程式修正了類別載入需花很長時間的問題，或涉及大量類別和產品時造成的逾時問題。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83時，即可使用此修補程式。 修補程式ID為ACP2E-5205。 請注意，此問題已排程在Adobe Commerce 2.4.9中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.8-p3

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） >= 2.4.8 &lt; 2.4.9

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

類別載入需要很長時間，或涉及大量類別和產品時造成逾時問題。

<u>要再現的步驟</u>：

1. 建立&#x200B;*2500* **[!UICONTROL Categories]**&#x200B;且至少&#x200B;*10000* **[!UICONTROL Products]**：
   1. 建立`setup/performance-toolkit`的復本，並將其放到`./var`以便編輯設定檔。
   1. 編輯`small.xml`設定檔，並設定&#x200B;**[!UICONTROL Categories]** = *2500*&#x200B;和&#x200B;**[!UICONTROL Products]** = *250000*。
   1. 執行`bin/magento setup:performance:generate-fixtures var/setup/performance-toolkit/profiles/ce/small.xml`。
1. 建立產品和類別後，請確定它們都是錨點，然後執行查詢：

   ```UPDATE catalog_category_entity_int set value = 1 where attribute_id = (select attribute_id from eav_attribute where attribute_code = 'is_anchor');
   
   ```
 
1. 前往管理員功能表，確定您擁有更深入的類別結構，然後將類別2更深入到類別1樹狀結構。
1. 重新索引。

<u>預期結果</u>：

每個類別都會從第一次未快取重試時開啟，而且只需要幾秒鐘的時間。

<u>實際結果</u>：

開啟類別需要超過一分鐘的時間。
