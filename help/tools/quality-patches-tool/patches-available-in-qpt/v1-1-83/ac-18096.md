# AC-18096：銷售GraphQL日期欄位傳回不正確的當地語系化格式

AC-18096修補程式修正了銷售GraphQL日期欄位傳回日期時，格式與先前版本不同的問題，將日期格式從斜線分隔的`/`還原為虛線分隔的`-`。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83時，即可使用此修補程式。 修補程式ID為AC-18096。 請注意，此問題已在Adobe Commerce 2.4.9中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.9

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） >2.4.8 &lt;=2.4.9-p1

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hant)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

銷售GraphQL日期欄位會以斜線分隔的格式`(d/m/Y H:i:s)`傳回日期與時間值，而非Adobe Commerce 2.4.8中使用的虛線分隔格式`(Y-m-d H:i:s)`

<u>必要條件</u>：

- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Timezone]**： *歐洲/巴黎*
- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Locale]**： *法文（法國）*

<u>要再現的步驟</u>：

1. 建立訂單。
1. 使用GraphQL擷取訂單日期詳細資料：

   ```graphql
   query getOrders {
       customer {
           orders {
               items {
                   orderDateOK: created_at
                   orderDateFAIL: order_date
               }
           }
       }
   }
   ```

<u>預期結果</u>：

- 欄位傳回`Y-m-d H:i:s`中的值，符合2.4.8版的輸出。

<u>實際結果</u>：

- 欄位傳回`d/m/Y H:i:s`中的值，例如`27/08/2026 14:12:55`，而非`Y-m-d H:i:s`，例如`2026-08-27 14:12:55`。
