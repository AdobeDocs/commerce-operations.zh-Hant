# ACP2E-4639：請購單清單專案型別在Adobe Commerce GraphQL結構描述中拼寫錯誤

ACP2E-4639修補程式修正GraphQL結構描述中請購單清單專案型別拼字錯誤的問題。 新的`requisition_list_items`欄位會傳回拼寫正確的`RequisitionListItems`型別，而舊的`items`欄位和`RequistionListItems`型別仍可使用，但已過時。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83時，即可使用此修補程式。 修補程式ID為ACP2E-4639。 請注意，此問題已在Adobe Commerce B2B 1.5.3中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） B2B 1.5.2 - p1

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） B2B >= 1.3.4 &lt; 1.5.3

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

請購單清單專案型別在GraphQL結構描述中拼寫為`RequistionListItems`錯誤。 較舊的`items`欄位和`RequistionListItems`型別仍可使用，但已過時。

<u>必要條件</u>：

Adobe Commerce搭配B2B擴充功能。

<u>要再現的步驟</u>：

1. 傳送下列GraphQL內部檢查查詢：

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. 在回應中，檢查`items`欄位傳回的型別。

<u>預期結果</u>：

1. `requisition_list_items`欄位傳回拼寫正確的`RequisitionListItems`型別。
1. `items`欄位和`RequistionListItems`型別仍可使用，並標籤為已棄用。

<u>實際結果</u>：

`items`欄位傳回拼寫錯誤的`RequistionListItems`型別，沒有欄位傳回拼寫正確的`RequisitionListItems`型別。
