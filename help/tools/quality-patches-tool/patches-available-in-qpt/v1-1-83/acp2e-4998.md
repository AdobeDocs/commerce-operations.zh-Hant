# ACP2E-4998：缺少SKU導致有效產品的批次層級價格更新無法進行

ACP2E-4998修補程式修正裝載中有一個SKU不存在時，`POST /V1/products/tier-prices` REST API要求完全失敗的問題，以防止更新有效的SKU。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83時，即可使用此修補程式。 修補程式ID為ACP2E-4998。 請注意，此問題已排程在Adobe Commerce 2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.7 - p10

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） >= 2.4.7 &lt; 2.4.8

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

當承載中不存在一個SKU時，`POST /V1/products/tier-prices` REST API要求完全失敗，導致無法更新有效的SKU。

<u>要再現的步驟</u>：

1. 識別一個現有的產品SKU （例如`product_dynamic_1`）和一個不存在於目錄中的SKU （例如`product_dynamic_001`）。
1. 將POST要求提交至`/rest/V1/products/tier-prices`，其中包含相同承載中的兩個SKU：

   ```json
   {
     "prices": [
       {
         "sku": "product_dynamic_1",
         "customer_group": "General",
         "quantity": 5,
         "price": 31.99,
         "price_type": "fixed",
         "website_id": 0
       },
       {
         "sku": "product_dynamic_001",
         "customer_group": "General",
         "quantity": 5,
         "price": 54.49,
         "price_type": "fixed",
         "website_id": 0
       }
     ]
   }
   ```

<u>預期結果</u>：

1. 已針對現有SKU儲存層級價格。
1. 回應會將遺失的SKU報告為料號層次錯誤。

<u>實際結果</u>：

1. 要求失敗，錯誤為&#x200B;*SKU為&#39;&#39;%1&#39;&#39;的產品不存在。* 針對`product_dynamic_001`。
1. 未儲存現有SKU的層級價格。
