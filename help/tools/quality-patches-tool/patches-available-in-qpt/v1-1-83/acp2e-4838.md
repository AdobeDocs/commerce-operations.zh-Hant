# ACP2E-4838：受限管理員使用者無法從允許的網站刪除客戶

ACP2E-4838修補程式修正了具有受限制許可權的管理員使用者無法從客戶格線中刪除客戶的問題。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83時，即可使用此修補程式。 修補程式ID為ACP2E-4838。 請注意，此問題已排程在Adobe Commerce 2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.8-p3

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） >=2.4.4 &lt;2.4.10

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

具有受限制許可權的管理員使用者無法從客戶格線中刪除客戶。

<u>要再現的步驟</u>：

1. 在管理面板中，移至&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL All Stores]**。 確認&#x200B;**[!UICONTROL Main Website]**&#x200B;有預設值&#x200B;**[!UICONTROL Main Website Store]**&#x200B;和&#x200B;**[!UICONTROL Default Store View]**。 建立下列專案：
   * 商店：按一下&#x200B;**[!UICONTROL Create Store]**，將&#x200B;**[!UICONTROL Web Site]**&#x200B;設為&#x200B;**[!UICONTROL Main Website]**，在&#x200B;**[!UICONTROL Name]**&#x200B;中輸入`Group A`，輸入唯一的&#x200B;**[!UICONTROL Code]**，然後按一下&#x200B;**[!UICONTROL Save Store]**。
   * 商店檢視：按一下&#x200B;**[!UICONTROL Create Store View]**、將&#x200B;**[!UICONTROL Store]**&#x200B;設為&#x200B;**[!UICONTROL Group A]**、在&#x200B;**[!UICONTROL Name]**&#x200B;中輸入`Store View A`、輸入唯一的&#x200B;**[!UICONTROL Code]**、將&#x200B;**[!UICONTROL Status]**&#x200B;設為&#x200B;**[!UICONTROL Enabled]**，然後按一下&#x200B;**[!UICONTROL Save Store View]**。
1. 透過&#x200B;**[!UICONTROL Default Store View]**&#x200B;建立客戶帳戶，讓客戶屬於&#x200B;**[!UICONTROL Main Website]**&#x200B;和&#x200B;**[!UICONTROL Default Store View]**。
1. 前往&#x200B;**[!UICONTROL System]** > **[!UICONTROL Permissions]** > **[!UICONTROL User Roles]**，然後按一下&#x200B;**[!UICONTROL Add New Role]**。
1. 在&#x200B;**[!UICONTROL Role Resources]**&#x200B;中，選取&#x200B;**[!UICONTROL Customers]** > **[!UICONTROL All Customers]**&#x200B;及其&#x200B;**[!UICONTROL Delete]**&#x200B;許可權。
1. 在&#x200B;**[!UICONTROL Role Scopes]**&#x200B;中，為&#x200B;**[!UICONTROL Main Website]**&#x200B;選取&#x200B;**[!UICONTROL Custom]**&#x200B;並僅允許`Group A`，保留&#x200B;**[!UICONTROL Main Website Store]**&#x200B;未選取。
1. 建立管理員使用者並將其指派給受限制的角色。
1. 以受限制使用者的身分登入「管理員」面板。
1. 前往&#x200B;**[!UICONTROL Customers]** > **[!UICONTROL All Customers]**。
1. 選取客戶，然後從&#x200B;**[!UICONTROL Actions]**&#x200B;下拉式功能表中選取&#x200B;**[!UICONTROL Delete]**。

<u>預期結果</u>：

受限制的管理員使用者可以開啟和刪除客戶，因為客戶的網站在角色範圍內，即使客戶是在角色範圍以外的商店檢視中建立的。

<u>實際結果</u>：

客戶未被刪除，且管理員顯示下列錯誤訊息： *需要更多許可權才能檢視此專案。*
