# AC-17975：PHP 8.5相容性問題會影響CLI命令、類別編輯、設計組態和客戶登入

AC-17975修補程式修正了使用PHP 8.5時，Adobe Commerce 2.4.9中的CLI命令、類別編輯、設計設定和AJAX客戶登入失敗的問題。 安裝[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83時，即可使用此修補程式。 修補程式ID為AC-17975。 請注意，此問題已排程在Adobe Commerce 2.4.9-p1和2.4.10中修正。

## 受影響的產品和版本

**已為Adobe Commerce版本建立修補程式：**

* Adobe Commerce （所有部署方法） 2.4.9

**與Adobe Commerce版本相容：**

* Adobe Commerce （所有部署方法） 2.4.9

>[!NOTE]
>
>此修補程式可能適用於發行版本為[!DNL Quality Patches Tool]的其他版本。 若要檢查修補程式是否與您的Adobe Commerce版本相容，請將`magento/quality-patches`套件更新至最新版本，並在[[!DNL Quality Patches Tool]上檢查相容性：搜尋修補程式頁面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)。 使用修補程式ID作為搜尋關鍵字，以尋找修補程式。

## 問題

當Adobe Commerce 2.4.9在PHP 8.5上執行時，CLI命令、類別編輯、設計設定和AJAX客戶登入會失敗。

<u>必要條件</u>：

已安裝PHP 8.5。

<u>要再現的步驟</u>：

1. 執行下列CLI命令：

   ```
   bin/magento --version
   ```

1. 在店面，當客戶驗證碼已啟用登入和結帳時，完成結帳並在結帳期間登入。
1. 在Admin中，當類別屬性的`frontend_input`設定為`null`時開啟類別。
1. 在Admin中，移至&#x200B;**[!UICONTROL Content]** > **[!UICONTROL Design]** > **[!UICONTROL Configuration]**，然後按一下&#x200B;**[!UICONTROL Action]**&#x200B;欄中的&#x200B;**[!UICONTROL Edit]**&#x200B;以檢視商店。


<u>預期結果</u>：

所有作業都已順利完成。


<u>實際結果</u>：

作業會因錯誤而失敗，例如：

```
Exception #0 (Exception): Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead
/var/www/html/vendor/magento/framework/App/Config/ScopeCodeResolver.php on line 62
```

```

```

```

Undefined constant "Magento\Framework\Setup\Mvc\GLOB_BRACE"
```

```

```
