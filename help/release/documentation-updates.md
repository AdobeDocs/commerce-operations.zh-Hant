# 檔案更新

此頁面包含有關[Experience League](https://experienceleague.adobe.com/zh-hant/docs/commerce)和[Adobe Developer](https://developer.adobe.com/commerce/docs/)的Adobe Commerce技術檔案的更新。 使用這些清單來尋找新主題、修改後的指引，以及根據讀者意見回應所進行的改進。

意見驅動變更可解決讀者的建議或問題，例如說明不清楚、遺漏詳細資訊或不準確資訊。 例如，意見反應導致[產品推薦檔案](https://experienceleague.adobe.com/zh-hant/docs/commerce/product-recommendations/boundaries-limits)中套件和群組產品支援的更正。

## 提供意見回饋

您的意見反應有助於改善說明檔案。 您可以透過下列方式協助撰寫：

* 在Experience League上，使用主題底部的意見回饋區域來評估其實用性，並留下評論。 請參閱[Adobe檔案貢獻者指南](https://experienceleague.adobe.com/zh-hant/docs/contributor/contributor-guide/introduction)，瞭解報告問題和建議編輯的相關指示。
* 在Adobe Developer上，使用從主題連結的公用GitHub存放庫來報告檔案問題或建議編輯。

加入主題URL，並說明不清楚、遺漏或錯誤的內容，讓檔案團隊可瞭解您的建議。
