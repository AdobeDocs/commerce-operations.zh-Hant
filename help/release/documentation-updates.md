# 檔案更新

此頁面列出[Adobe Experience League](https://experienceleague.adobe.com/zh-hant/docs/commerce)和[Adobe Developer](https://developer.adobe.com/commerce/docs/)的Adobe Commerce技術檔案更新。 使用這些清單來尋找新主題、修改後的指引，以及根據讀者意見回應所進行的改進。

意見驅動變更可解決讀者的建議或問題，例如說明不清楚、遺漏詳細資訊或不準確資訊。 例如，意見反應導致[產品推薦檔案](https://experienceleague.adobe.com/zh-hant/docs/commerce/product-recommendations/boundaries-limits)中套件和群組產品支援的更正。

## 提供意見回饋

您的意見反應有助於改善說明檔案。 您可以透過下列方式協助撰寫：

* 在Adobe Experience League上，使用右側邊欄中的意見區域或窄熒幕上頁面底部的意見區域。 按一下向上或向下縮圖按鈕，對主題進行評級並顯示可選的註解欄位。 若要留下註解，請輸入您的意見反應，然後按一下&#x200B;**[!UICONTROL Submit]**。 請參閱Adobe Experience League [&#128279;](https://experienceleague.adobe.com/zh-hant/docs/contributor/contributor-guide/introduction)上的Adobe檔案投稿人指南，瞭解報告問題和建議編輯的指示。
* 在Adobe Developer上，使用從主題連結的公用GitHub存放庫來報告檔案問題或建議編輯。 如需指示，請參閱Adobe Developer[&#128279;](https://developer.adobe.com/commerce/contributor/guides/doc-contributions/)上的說明檔案協助撰寫。

加入主題URL，並說明不清楚、遺漏或錯誤的內容，讓檔案團隊可瞭解您的建議。
