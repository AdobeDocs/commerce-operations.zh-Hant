# 專案啟動

維持一個健康的電子商務網站，對於您的企業成功同樣至關重要，與您的初始啟動一樣，關鍵方面是主動規劃和準備升級，以協助您的網站儘可能順暢地運作。

在此期間若未設定正確的升級期望，會導致未來不滿意。 請確定您已瞭解並瞭解[發行步調](/help/release/schedule.md)，並使用此指南來協助您定義規劃升級的方式與時機。
